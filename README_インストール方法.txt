東京地理 — Androidスマホのアプリとしてインストールする方法

【まずすぐ使う】
別添の「東京地理_スマホ単体版.html」をAndroidでダウンロードし、「ファイル」からChromeなどで開いてください。オフラインでも教材を利用できます。ただしこれは「通常のインストールされたアプリ」ではありません。

【ホーム画面にアプリアイコンを置く（推奨）】
1. このZIPを展開し、中の index.html / manifest.webmanifest / sw.js / PNGなどをすべて同じフォルダに置きます。
2. GitHubのリポジトリを作成し、ZIP内のファイルをすべてリポジトリのルートへアップロード（ZIPのままアップロードしない）。
3. GitHubのリポジトリ設定 → Settings → Pages → Build and deployment → Deploy from a branch → main と /(root) → Save。
4. Pagesで表示された https://...github.io/.../ のURLを、GalaxyのChromeで開きます。
5. 右上の ⋮ →「アプリをインストール」または「ホーム画面に追加」を選択します。環境によって表記は変わります。
6. ホーム画面に「東京地理」のアイコンが追加され、通常のアプリのように起動できます。一度読み込めば教材はオフラインで使えます。

【重要】
・PWAはAPKではありません。HTTPS上でアクセスして初めてインストールできます。
・GitHub Pagesの公開内容は、Privateリポジトリから出してもサイトが公開される場合があります。配布問題などの権利を確認してから公開してください。
・Googleマップへの外部リンクはオフライン時には開けません。
・学習履歴はAndroid内のブラウザ保存領域に記録されます。「一覧・検索」から履歴を書き出し・復元できます。キャッシュ/サイトデータ削除で消える可能性があります。
・HTML単体版とPWA版では保存領域が違い、履歴が自動移行されるわけではありません。
